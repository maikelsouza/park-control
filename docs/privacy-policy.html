Política de Privacidade do ParkControl

Última atualização: 17 de outubro de 2026

O ParkControl ("o App") é um aplicativo de gestão de estacionamentos desenvolvido para uso local pelo operador do estabelecimento (ex.: controle de entradas, saídas, mensalistas e veículos). Esta Política de Privacidade descreve como os dados são tratados dentro do App.

1. Dados coletados

O ParkControl não coleta, não envia e não compartilha nenhum dado com servidores externos, terceiros ou com o desenvolvedor. Todas as informações inseridas no App são armazenadas exclusivamente no próprio dispositivo do usuário, utilizando armazenamento local (banco de dados Room e DataStore do Android).

Os tipos de dados que podem ser cadastrados pelo próprio usuário/operador do estacionamento incluem:

  • Dados de clientes mensalistas: nome, telefone, e-mail e sexo (opcional).
  • Dados de veículos: placa, marca, modelo, cor, categoria e vaga.
  • Registros de estacionamento: horário de entrada/saída, placa, telefone, valores pagos e descontos aplicados.
  • Configurações do estacionamento: preços, tolerância e regras de cobrança definidas pelo operador.

2. Como os dados são usados

Esses dados são utilizados apenas para o funcionamento das funcionalidades do próprio App (controle de vagas, cálculo de tarifas, histórico de mensalistas e acordos/convênios). Nenhuma informação é utilizada para publicidade, análise de comportamento, perfis de usuário ou qualquer finalidade fora do contexto operacional do estacionamento.

3. Permissões do aplicativo

O ParkControl não requer acesso à internet, câmera, localização, contatos, armazenamento externo ou qualquer outra permissão sensível do dispositivo. O App funciona de forma totalmente offline.

4. Compartilhamento de dados

Como todos os dados permanecem armazenados localmente no dispositivo, não há compartilhamento com servidores, serviços em nuvem, anunciantes ou terceiros de qualquer tipo.

5. Armazenamento e segurança

Os dados ficam armazenados no armazenamento interno do próprio dispositivo Android, protegidos pelo sandboxing de aplicativos do sistema operacional. Caso o usuário realize backup do dispositivo (recurso nativo do Android), os dados do App podem ser incluídos conforme as regras padrão de backup do Android, sob controle do próprio usuário.

6. Exclusão de dados

O usuário pode apagar todos os dados do App a qualquer momento através de:

  • Exclusão de registros/clientes diretamente nas telas do App; ou
  • Limpeza de dados do aplicativo nas configurações do Android (Configurações > Apps > ParkControl > Armazenamento > Limpar dados); ou
  • Desinstalação completa do aplicativo.

7. Dados de crianças

O ParkControl não é direcionado a crianças e não coleta intencionalmente dados de menores de idade.

8. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir melhorias ou mudanças no App. A data da última atualização estará sempre indicada no topo desta página.

9. Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato através do e-mail: parkcontrol.sistema@gmail.com
